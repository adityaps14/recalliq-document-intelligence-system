RecallIQ is a local document intelligence prototype. It helps users search notes and retrieve relevant passages. TF-IDF converts text into weighted word vectors and cosine similarity ranks passages by similarity to a query. The ranking is lexical, so it works best when the query shares meaningful words with the source. PDF extraction works only when a PDF contains selectable text. Scanned image PDFs need OCR, which is not included in this starter version. The summarizer in this project is extractive and selects the first useful sentences. It does not call a generative AI model. A future version could add embeddings or an LLM API and cite the exact source passages used in an answer.
